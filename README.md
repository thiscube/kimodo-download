# Kimodo

Make Roblox R15 animations from text, and edit them by chatting.

## Download

1. Go to [Releases](https://github.com/thiscube/kimodo-download/releases/latest) and download `Kimodo-vX.zip`.
2. Unzip it into a folder you'll keep, like `Documents\Kimodo`.
3. Open `Kimodo.exe`. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

The first time it opens, a setup window installs everything (about 20 GB, up to an hour).
It asks for a free Hugging Face key, because Meta only lets signed-in people download the Llama model Kimodo uses.
The window explains each step.

## What your PC needs

- An NVIDIA graphics card with 8 GB or more
- 16 GB of memory
- About 25 GB of free disk space
- Windows 10 or 11

## Updates

When a new version is out, Kimodo shows an **Update** button at the top left. Click it and Kimodo updates itself
and opens again. Your animations and chats stay.

## Chat

The chat on the right uses your own Claude or ChatGPT account. Sign in from the chat panel.
